# Pósters de la cartelera

Coloca aquí las imágenes que se suministrarán para la interfaz. La aplicación
las detecta automáticamente al reiniciarse. Se admiten `.webp`, `.jpg`, `.jpeg`
y `.png`, en ese orden de prioridad.

Formato recomendado: orientación vertical 2:3, mínimo 600 × 900 píxeles y menos
de 1 MB por archivo.

## Nombres requeridos

| Película | Archivo base |
|---|---|
| El Conjuro | `el_conjuro` |
| It | `it` |
| Annabelle | `annabelle` |
| Toy Story | `toy_story` |
| Buscando a Nemo | `nemo` |
| Intensamente | `intensamente` |
| Coco | `coco` |
| Encanto | `encanto` |
| Shrek | `shrek` |
| Mi villano favorito | `villano` |
| Deadpool | `deadpool` |
| Joker | `joker` |
| Coraline | `coraline` |
| Hotel Transilvania | `hotel` |
| Titanic | `titanic` |
| Caso sintético de prueba | `caso_terror_infantil` |

Ejemplo: `titanic.webp` o `titanic.jpg`.

Mientras un archivo no exista, la tarjeta muestra un póster de reserva con el
título y el mensaje «Póster pendiente de suministrar».
